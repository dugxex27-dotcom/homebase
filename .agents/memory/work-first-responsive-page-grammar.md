---
name: Work-first responsive page grammar
description: Approved cross-role layout policy for authenticated MyHomeBase web and mobile surfaces.
---

Authenticated pages should use a compact title row with one primary action, put the current work or list in the first viewport, and keep scores or context in a slim supporting module. Avoid repeating full-width gradient heroes. Mobile controls must remain clear of persistent install prompts and fixed navigation.

On desktop, dashboard content should use the pane beside the sidebar fluidly with modest gutters. A shared maximum around 1400px is appropriate; do not center the main dashboard in a narrow 1100–1150px island on wide screens.

The stable primary navigation is Home / Maintain / Record / Pros / More for homeowners, Jobs / Messages / Clients / Profile for contractors, and Dashboard / Handoffs / Referrals / Account for agents.

**Why:** Large decorative headers and hidden destinations delayed useful work, while narrow centered desktop wrappers left conspicuous empty gutters beside the sidebar and made the dashboard feel disconnected.

**How to apply:** Preserve this grammar when adding or redesigning authenticated pages. Put secondary tools behind the role's final account/more destination rather than expanding primary navigation or adding flyouts.
