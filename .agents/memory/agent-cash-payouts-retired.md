Real-estate-agent referral cash payouts are permanently retired. Do not create new payout rows, advance payout eligibility, initiate Stripe transfers, send payout emails, expose payout APIs or UI, or use cash-earning claims in agent copy. Historical ledger schema and records remain for integrity.

**Why:** The product owner explicitly removed the $15 agent payout program and wants Agent Hub value centered on a free closing gift, client loyalty, listing prep, and co-branded reports.

**How to apply:** Preserve general agent referral attribution and non-cash relationship tools, plus the separate homeowner/contractor subscription-credit programs. Never reintroduce agent “earn money,” commission, payout, or earnings functionality or messaging.
